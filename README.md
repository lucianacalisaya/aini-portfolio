# Aini's portfolio
 
A portfolio site for Aini, an artist from Argentina, in English and Korean. She uses it to present her music, videos and experience.
 
**Live:** https://lucianacalisaya.github.io/aini-portfolio/
 
## What it does
 
- One long page with a table of contents: introduction, experience, more about her, project, cover letter and contact
- Every text in English and Korean
- Animations that start as you scroll (stars, a typewriter effect, flipping cards)
- Smooth scrolling from the table of contents to each section
- Layout for tablet and laptop screens
 
## Built with
 
HTML, SCSS, JavaScript (jQuery)
 
## My part
 
Aini designed the pages in Canva. I turned the design into code from scratch, wrote all the styles and made the animations myself.
 
## Run it locally
 
Download or clone the repo and open `index.html` in a browser. The styles are written in `scss/style.scss` and compiled to `css/style.css`.
